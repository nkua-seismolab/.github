# Seismological Laboratory - NKUA

Welcome to the official GitHub organization of the **Seismological Laboratory** of the National and Kapodistrian University of Athens. 

This space hosts open-source code, computational tools, and data processing scripts developed by our research team.

### Research Areas
* Observational Seismology
* Seismotectonics
* Applied Machine Learning in Seismology
* Seismic Hazard
* Earthquake Early Warning Systems
* Shear-wave Splitting
